# Java Programming Lab Portfolio

This repository contains a comprehensive collection of core Java programming implementations developed as part of the CS25C09 Java Programming Lab curriculum[cite: 1]. It highlights practical applications of Object-Oriented Programming (OOP), event handling, multithreading, file management, and database connectivity.

---

## 🚀 Key Topics Covered

1. **Constructors**: Object initialization[cite: 1] (`Ex.No.1`)
2. **Static Members**: Class-level variables and methods (`Ex.No.2`)
3. **Inheritance**: Code reusability via `super` and subclassing (`Ex.No.3`)
4. **Packages**: Custom package creation and importing (`Ex.No.4`)
5. **Interfaces**: Implementing multiple behavior contracts (`Ex.No.5`)
6. **Access Specifiers**: `public`, `private`, `protected`, and default scope (`Ex.No.6`)
7. **Exception Handling**: Custom user-defined exception propagation (`Ex.No.7`)
8. **Multithreading**: Concurrent execution using the `Thread` class (`Ex.No.8`)
9. **String Handling**: Manipulation using built-in string APIs (`Ex.No.9`)
10. **AWT & Swing**: GUI components and event listeners (`Ex.No.10`, `Ex.No.12`)
11. **File I/O**: Stream-based reading and writing (`Ex.No.11`)
12. **JDBC**: MySQL database connectivity and CRUD execution (`Ex.No.13`)
13. **Collections Framework**: Dynamic data structures (`ArrayList` & `HashMap`) (`Ex.No.14`)

---

## 🛠️ Technologies Used
* **Language:** Java (JDK 17+)
* **GUI Libraries:** Java AWT & Swing
* **Database:** MySQL & JDBC (`mysql-connector-j`)
* **Tools:** Git, GitHub, VS Code / Eclipse / IntelliJ IDEA
